# Bài 12 - Định Hướng Nâng Cao Sau Lộ Trình

## Mục tiêu

- Biết các hướng học tiếp theo sau khi xong nền tảng.
- Có kế hoạch học 2-3 tháng tiếp theo.
- Biết cách xây hồ sơ dự án cá nhân từ sớm.

## Hướng 1: Python tự động hóa

Bạn sẽ học cách:

- Đọc/ghi file hàng loạt.
- Đổi tên file tự động.
- Tự động làm các việc lặp lại.

Ví dụ dự án:

- Tự động sắp xếp file theo thư mục.
- Tạo báo cáo điểm tự động từ file dữ liệu.

## Hướng 2: Python làm game cơ bản

Bạn sẽ học:

- Làm quen với `pygame`.
- Quản lý nhân vật, điểm số, va chạm.
- Thiết kế vòng lặp game.

Ví dụ dự án:

- Game đoán số.
- Game né vật cản.
- Game bắt bóng.

## Hướng 3: Python cho dữ liệu

Bạn sẽ học:

- Đọc dữ liệu CSV bằng `pandas`.
- Lọc, sắp xếp, thống kê dữ liệu.
- Vẽ biểu đồ cơ bản.

Ví dụ dự án:

- Phân tích điểm lớp.
- Thống kê thói quen học tập theo tuần.

## Hướng 4: Thuật toán và thi học sinh giỏi Tin

Bạn sẽ học:

- Mảng, chuỗi, đệ quy cơ bản.
- Tư duy tối ưu và phân tích độ phức tạp đơn giản.
- Kỹ năng giải bài trong thời gian giới hạn.

## Kế hoạch 8 tuần đề xuất

1. Tuần 1-2: Ôn bài 1-6 và làm lại bài tập khó.
2. Tuần 3-4: Hoàn thiện dự án quản lý điểm.
3. Tuần 5-6: Chọn 1 hướng (game hoặc dữ liệu) để đào sâu.
4. Tuần 7-8: Làm dự án cá nhân và trình bày lại cho gia đình/bạn bè.

## Tiêu chí đánh giá tiến bộ

- Viết code rõ ràng, dễ đọc.
- Giảm số lỗi cơ bản (dấu `:`, indent, sai tên biến).
- Tự tìm lỗi và sửa được mà không cần chép đáp án.
- Có ít nhất 2 dự án hoàn chỉnh.

## Mẹo học bền vững

- Mỗi tuần code ít nhất 3 buổi.
- Mỗi buổi 45-60 phút.
- Sau mỗi chương trình, tự hỏi:
  - Code này có dễ đọc không?
  - Mình có thể tách thành hàm tốt hơn không?
  - Nếu dữ liệu lớn hơn thì chương trình còn ổn không?
