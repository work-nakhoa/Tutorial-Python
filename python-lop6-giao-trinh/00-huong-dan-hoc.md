# Bài 00 - Hướng Dẫn Học Python Hiệu Quả

## Mục tiêu

- Biết chuẩn bị môi trường học Python.
- Hiểu cách học lập trình đúng từ đầu.
- Biết cách đọc lỗi và tự sửa lỗi cơ bản.

## Cần chuẩn bị gì?

- Python 3.x đã cài trên máy.
- Một trình soạn thảo: VS Code hoặc Thonny.
- Terminal (Mac/Linux) hoặc Command Prompt/PowerShell (Windows).
- Một cuốn sổ hoặc file ghi chú để ghi lỗi và cách sửa.

## Kiểm tra máy đã có Python chưa

Mở terminal và chạy:

```bash
python3 --version
```

Nếu thấy kết quả dạng `Python 3.x.x` là ổn.

## Chương trình đầu tiên

```python
print("Xin chào Python!")
print("Mình là học sinh lớp 6.")
```

Ý nghĩa:

- `print()` dùng để in thông tin ra màn hình.
- Mỗi lệnh nên đặt trên một dòng để dễ đọc.

## Quy trình học mỗi bài (rất quan trọng)

1. Đọc mục tiêu bài học.
2. Gõ lại toàn bộ ví dụ bằng tay.
3. Chạy code, quan sát kết quả.
4. Tự sửa ví dụ theo ý mình (đổi dữ liệu, đổi tên biến).
5. Làm bài tập từ dễ đến khó.
6. Tự giải thích lại bài cho người khác (hoặc tự nói lớn).

## 6 lỗi thường gặp khi mới học

1. Quên dấu `:` sau `if`, `for`, `while`, `def`.
2. Thụt đầu dòng sai (Python rất nhạy cảm với khoảng trắng).
3. Gõ sai tên biến (`diemToan` khác `diemtoan`).
4. Nhầm `=` (gán giá trị) và `==` (so sánh).
5. Quên dấu ngoặc hoặc dấu nháy.
6. Dùng tiếng Việt có dấu trong tên biến (nên tránh để ít lỗi).

## Mẹo sửa lỗi nhanh

- Đọc dòng báo lỗi cuối cùng trước.
- Xem số dòng lỗi, quay lại đúng dòng đó.
- Nếu chưa hiểu, chạy lại với đoạn code ngắn hơn.
- Không sửa quá nhiều chỗ cùng lúc.
